
# SEN College Finder – Frontend

Vite + React + Tailwind frontend with the **Instant Dossier Panel** and optional **Deep Dive**.

## Run (Windows)
```powershell
npm install
npm run dev
```
Open http://localhost:5173

## Connect to API
Create `.env` with:
```
VITE_API_BASE=http://localhost:8001
```
Restart `npm run dev`.

**Note**: The `VITE_API_BASE` environment variable is required. The dev backend runs on port 8001.
